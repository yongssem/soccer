# 미니 축구 · MINI MATCH

16개 국가대표 팀으로 즐기는 1인/2인 미니 축구. 원래 게임의 세로형 경기장, 진영 제한, 자동 수비수, 선취 득점 규칙을 유지했습니다.

## 실행

`index.html`을 직접 열거나 Node.js 20 이상에서 실행하세요.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4173`에 접속합니다. 런타임 패키지를 설치할 필요가 없습니다.

## 조작

| 동작 | 조작 |
| --- | --- |
| 아래쪽 선수 1 | WASD / 아래 진영 드래그 |
| 위쪽 선수 2 | 방향키 / 위 진영 드래그 |
| 일시정지 | Space / Escape / 화면 위 Ⅱ |
| 득점 | 선수로 공을 밀어 상대 골문에 넣기 |

한 기기에서 두 명이 함께 플레이할 수 있습니다. 온라인 대전 기능은 없습니다. 다른 탭이나 창으로 이동하면 자동으로 일시정지됩니다. 소리는 경기 하단에서 직접 켭니다.

## 배포

기존 정적 호스팅에 다음 파일을 같은 경로에 배포하세요. GitHub Pages의 하위 경로도 지원하는 상대 경로를 사용합니다.

`index.html`, `styles.css`, `tokens.css`, `game.js`, `icon.svg`, `icon-192.png`, `icon-512.png`, `manifest.webmanifest`

서버 API, 데이터베이스, API 키, 빌드 단계는 필요하지 않습니다. 공유·클립보드·전체화면·설치 기능은 브라우저 지원 여부와 권한에 따라 안내로 대체됩니다. 홈 화면 추가는 HTTPS로 호스팅한 뒤 확인해야 합니다. 서비스워커를 두지 않아 오프라인 캐시를 제공하지 않습니다.

## 검증

```sh
npm test
```

브라우저 흐름은 Playwright와 Chrome으로 검사합니다.

```sh
npm install --no-save playwright
npm run test:browser
```

기본 검사는 로컬 HTML을 엽니다. `TEST_URL`에 배포 주소를 지정하면 동일한 사용자 흐름을 해당 URL에서 검사합니다. `BROWSER_CHANNEL`로 설치된 브라우저 채널을, `SCREENSHOT_DIR`로 캡처 폴더를 지정할 수 있습니다.

`npm test`는 득점 방향, 진영 제한, 입력 해제, 일시정지, 중복 팀 방지, 리매치 초기화, 60/144Hz 일관성을 검사합니다. 브라우저 검사는 6개 뷰포트, 키보드, 두 손가락 동시 입력, 승리·재경기·종료를 검사합니다. 실물 모바일 기기의 음향·설치·OS 공유 시트는 별도 확인 대상입니다.
